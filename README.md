# 🎓 Pokemon Search

## 📖 Description
The application demonstrates server-side rendering with Next.js, routing, global state management, testing setup, and modern styling.  
It allows users to **search for Pokémon**, **save results**, **download them as CSV**, handle errors gracefully, and switch between **light/dark themes**.

## 🛠 Technologies Used
- **Next.js** + **React**
- **TypeScript**
- **TailwindCSS** for styling
- **Redux Toolkit** for state management
- **Vitest** + **React Testing Library** for testing
- **MSW (Mock Service Worker)** for API mocking
- ESLint + Prettier + Husky for code quality and pre-commit hooks

## ⚙️ How to Run

```bash
git clone https://github.com/vidfefe/rs-school.git
cd rs-school
npm install
npm run dev
```
